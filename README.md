# EarthLove Frontend

EarthLove è un'applicazione frontend sviluppata con **React** per la consultazione di un catalogo di prodotti sostenibili. Il progetto si integra con un backend realizzato in **Laravel** tramite API REST, consentendo agli utenti di visualizzare l'elenco dei prodotti, consultarne i dettagli e accedere alle informazioni correlate.

## Funzionalità

- **Visualizzazione dei prodotti:** consultazione dell'elenco degli elementi disponibili.
- **Scheda di dettaglio:** visualizzazione delle informazioni relative a un singolo prodotto.
- **Informazioni correlate:** visualizzazione delle categorie associate ai prodotti.
- **Integrazione API REST:** recupero dei dati dal backend Laravel tramite chiamate AJAX.
- **Rendering dinamico:** visualizzazione dei contenuti in React sulla base dei dati ricevuti dalle API.

## Tecnologie utilizzate

- JavaScript (ES6+)
- React
- HTML5
- CSS3
- API REST
- Chiamate AJAX
- Vite
- Git

## Obiettivo del progetto

Realizzare un'interfaccia frontend in React per la consultazione e la visualizzazione dei dati gestiti dal backend, sperimentando l'integrazione tra applicazioni frontend e backend attraverso API REST.
